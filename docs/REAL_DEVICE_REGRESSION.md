# 真实设备回归清单

本清单用于预览版发布前的手工验证。所有测试均在本机完成；不要提交 `profiles.json`、日志、设备 ID、应用路径或用户名。

## 准备

1. 使用一个隔离的 `PERDEVICEMIXER_DATA_DIRECTORY`，或先备份现有本地配置。
2. 在设置中开启“本地音频诊断”，以便出现问题后查看 `%LocalAppData%\PerDeviceMixer\logs\audio-events.log`。
3. 准备至少两个产生音频会话的应用，例如浏览器和播放器。

## 每种输出设备

分别对扬声器、有线耳机、蓝牙耳机和 HDMI 输出执行：

- 切换为默认输出，分别设置主音量、主静音和两个应用的音量；
- 切到另一台设备后再切回，确认仅恢复该设备自己的已保存值；
- 启动一个已保存应用和一个从未保存的新应用，确认前者恢复、后者保持 Windows 当前值；
- 从 Windows 音量合成器修改主音量、应用音量和静音，确认界面与 Profile 在保存延迟后更新；
- 拔出或断开设备，确认应用不退出；重新连接后确认可再次切换和恢复。

## 生命周期与压力

- 扬声器输出时插入有线耳机，确认自动切到有线耳机；再连接蓝牙耳机，确认自动切到蓝牙；断开蓝牙后回到有线，拔出有线后才回到扬声器；
- 扬声器输出时先连接蓝牙耳机，再插入有线耳机，确认自动切到有线；拔出有线后回到仍连接的蓝牙，最后断开蓝牙才回到扬声器；
- 每次上述切换发生时，屏幕底部应出现设备名与主音量提示：内容与当前默认输出一致，2.5 秒左右自动消失；连续切换（事件密集）时最长不超过 6 秒；提示区域鼠标点击可穿透、不抢焦点；
- 在设置页关闭“设备切换提示”后，再次切换设备不应出现提示；重新开启后恢复；
- 蓝牙耳机从盒内开盖或从断开状态重连时，记录耳机显示“已连接”和 Windows 默认输出切到蓝牙之间的耗时；若仍超过 2 秒，开启本地音频诊断并保留事件时间线；
- 连续切换默认输出至少 20 次；
- 连续创建和关闭音频会话至少 20 次；
- 让蓝牙设备断连、重连；如可用，重复 HDMI 热插拔；
- 让系统睡眠后恢复，再重复设备切换和音量调整；
- 关闭到托盘、重新打开窗口、再退出，确认配置保留且没有残留窗口；
- 在启用开机启动后卸载，确认 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run\PerDeviceMixer` 已删除。

## 记录结果

记录 Windows 版本、设备类型、复现步骤、预期与实际结果。若提供诊断日志，只提供日志本身；它不含原始设备 ID、应用路径或用户名，但仍应先自行审阅。
